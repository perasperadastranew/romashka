# Коттеджный посёлок «Ромашковая долина»

Концепт-сайт: девять домиков из сцены Blender в светлой изометрии на WebGL (three.js r128).

- `index.html` — вся страница: вёрстка, шейдеры, анимации.
- `map/` — модели (glTF в JSON) и маска дорожек и газонов `paths.png`.

Статичный сайт, сборка не нужна. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
